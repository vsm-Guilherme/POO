# POO
Repositório referente a matéria de POO


Projetos em Java da disciplina de Programação Orientada a Objetos.


1. Calculadora (Java Swing)

Calculadora com interface gráfica. Faz soma, subtração, multiplicação, divisão e potência, aceita ponto ou vírgula e tem o botão C para limpar.

2. ConsumirCep (API ViaCEP)

Consulta um CEP na API pública ViaCEP e mostra o resultado em JSON no console. O CEP é definido na variável cep do main. Não precisa de bibliotecas externas.

3. Poo-crudnuvem (CRUD com MySQL)

Programa de console com menu para inserir, listar, atualizar e deletar produtos. Os dados ficam em um banco MySQL no Railway, acessado por JDBC. A tabela PRODUTO (código, nome e preço) é criada automaticamente.

Antes de rodar, preencha a URL, o usuário e a senha do seu banco no início do main. É preciso adicionar o driver MySQL Connector/J ao projeto.
